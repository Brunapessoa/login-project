# Login Project

A responsive login screen built with HTML, CSS, and vanilla JavaScript, practicing form handling and DOM interaction.

## Features

- Login form with email and password fields, including native HTML validation (`required`, `maxlength`, `minlength`)
- "Forgot my password" flow: opens a modal where the user enters their email to request a reset
- On submit, the login form redirects to an external page (no backend/authentication — front-end practice only)
- Responsive layout with media queries

## Tech Stack

- HTML5
- CSS3 (Flexbox, media queries)
- Vanilla JavaScript (DOM manipulation, event listeners)

## Running locally

Clone the repo and open `index.html` in any modern browser — no build step or dependencies required.
